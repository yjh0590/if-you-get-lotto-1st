# IF 세계 · v0.8.1

로또 1등 당첨에서 시작해, 시대의 사건 속에서 자산을 바꾸고 원하는 삶을 살아보는 경제·인생 시뮬레이션입니다.
이 배포본은 파일 전달용입니다. 원격 저장소 업로드나 사이트 배포는 실행하지 않았습니다.

## 바로 실행하기

별도 패키지 설치가 필요 없는 정적 HTML/CSS/JavaScript 프로젝트입니다.
`dist/`의 모든 파일이 웹사이트 실행 파일입니다.
HTML을 더블클릭하지 말고 HTTP 서버로 실행하세요.

```bash
python3 -m http.server 8000 --directory dist
```

브라우저에서 http://localhost:8000 에 접속합니다.
Node.js 20 이상에서는 아래 명령으로 검증하고 별도 웹 폴더를 만들 수 있습니다.

```bash
npm test
npm run build
npm run export:web
```

`export:web` 결과는 `exports/if-world/`입니다.
기존 홈페이지에 넣거나 전용 GitHub Pages로 배포하는 방법은 `GITHUB-DEPLOY.md`를 참고하세요.

## 플레이 순서

1. 이름·나이·성별·거주 지역을 고릅니다.
2. 로또 회차 또는 달력의 구매 날짜·시간으로 추첨 회차를 정합니다.
3. 당첨금 지급 규칙과 최초 자산 배분을 확인한 뒤 추첨 연출을 봅니다.
4. 당첨 첫 주의 선택을 하고 ‘경제 시장’에서 자산을 매수·매도합니다.
5. ‘한 달만 진행’ 또는 ‘다음 사건까지’로 시간을 보냅니다.
6. 역사 사건·정책 변화와 보유 자산의 영향을 확인하고 다음 행동을 정합니다.
7. 집·차·명품·여행·가족·취미를 선택하고 삶의 기록을 쌓습니다.
8. 생애 종료 시 자산과 선택을 결산합니다. 중간 기록은 JSON으로 백업할 수 있습니다.

새 게임은 경제 중심으로 진행합니다.
‘삶과 함께’를 켜면 개인·직업·생활의 분기 사건도 함께 나옵니다.
별도의 1997년 시작 모드는 없습니다. 시작점은 로또 1회인 2002년 12월부터입니다.

## 경제 시장

- 원화 현금, 예금, 달러, 금을 보유하고 바꿀 수 있습니다.
- IF 분산시장과 반도체·디지털·헬스·여행·에너지·금융·생활소비의 가상 주식 7종을 거래합니다.
- 최초 배분 4종, 수량·평균 매입 원가·평가액·평가 손익·실현 손익·거래 기록을 제공합니다.
- 달러는 환율, 금은 달러 기준 금값과 환율을 함께 반영합니다.
- 예금 이자는 당시 게임 모형 금리로 계산합니다. 물가는 생활비·소비 가격에 반영합니다.
- 주식 0.2%, 달러 0.4%, 금 0.5%의 게임 수수료가 있습니다.
- 차트는 플레이한 기간의 가격만 보여줍니다. 미래 가격을 미리 열람할 수 없습니다.

### 정부와 정책

세계 경제 사건 11개와 정부 취임·정책 발표 사건 8개를 연결했습니다.
정부 취임 자체를 현금 보너스나 즉시 주가 상승으로 처리하지 않습니다.
발표된 방향을 다음 달부터 산업 테마의 흐름, 환율 변동 민감도, 금리·물가 모형의 기준에 연결합니다.
대통령 이름만으로 환율의 상승·하락 방향을 정하지 않습니다.

정책 발표가 취임보다 늦으면 발표 전까지 그 방향을 소급 적용하지 않습니다.
정책 시나리오의 효과는 시간이 지나며 줄어들고 최대 60개월 뒤 종료됩니다.
정책 화면은 발표 주제, 영향을 주는 경로, 사실의 출처와 게임 가정을 구분합니다.
이 화면은 실제 재임 기간 전체를 재현하는 정부 현황표가 아닙니다. 권한대행 기간 등은 별도 모델링하지 않았습니다.

### 시장 계산

같은 날짜의 시장 경로는 동일합니다. 저장을 다시 불러와도 바뀌지 않습니다.
월별 시장 계산 후 사건을 확인하고 자산을 조정합니다.
같은 사건의 충격을 중복 적용하지 않습니다.
사건 보고서는 그때 보유한 수량의 가격 효과이며 이자·생활비 등 전체 월 수지를 대신하지 않습니다.

시작 월의 가격에는 해당 월 사건이 포함되어 있습니다.
시작 월 사건 때문에 최초 자금에 손익을 소급 부과하지 않습니다.
실제 추첨일은 기록하지만 이후 경제 진행은 월 단위이며, 당첨일 전후의 일별 시장 순서는 재현하지 않습니다.
2026년 10월 이후 사건과 가격은 가상 미래로 표시합니다.

## 생활 콘텐츠와 화면

밝은 화이트·블루 화면과 반응형 레이아웃을 사용합니다.
상단에 자산을, 본문에 사건과 선택을, 시장 탭에 거래와 차트를 배치했습니다.
축소 모션, 키보드 포커스, 추첨 연출 건너뛰기를 지원합니다.
문장은 읽기 쉽게 나누고, 금액은 세 자리 쉼표와 억/만 원 환산을 함께 표시합니다.

집 5종, 차 6종, 소장품 5종, 여행 3종을 선택할 수 있습니다.
‘나의 공간’에는 당첨 첫 주, 방 꾸미기, 가족 지원, 취미, 버킷리스트와 추억이 있습니다.
개인 상황에 따른 21개 이야기 분기, 이사, 생애 앨범도 유지했습니다.
상품은 실제 브랜드나 매물이 아닌 게임 유형입니다.

## 자료와 중요한 한계

**가격·수익률·정책 효과 계수는 게임 가정입니다. 실제 과거 금융 시계열은 연결하지 않았습니다.**
사건의 사실·발생일·출처와 경제 효과를 분리했습니다.
발표된 정책 방향이 실제 경제 성과를 일으켰다는 통계적 추정이 아닙니다.
세금·공매도·레버리지·배당·외화 이자·실물 금의 보관비·일별 거래는 반영하지 않았습니다.
급여·사업·주거 가격·생활 효과도 게임 가정입니다.
실제 시계열을 연결할 때에는 가격에 이미 포함된 사건 영향을 다시 더하지 않아야 합니다.

로또 1~1245회 번호·보너스·추첨일·1등 인원·1인당 세전 금액을 내장했습니다.
민간 API와 과거 공식 API 사본을 활용했습니다.
1~1156회 핵심 항목은 두 공급처가 일치하며 최근 89회는 단일 공급처입니다.
전 회차 공식 원본 대조는 미완료입니다. 출처와 차이는 `data-validation.json`에 있습니다.
당첨자가 없는 회차는 가상 1명에게 배정액을 지급합니다.
기존 당첨자를 대체하거나 가상 당첨자를 추가하는 지급 규칙을 선택할 수 있습니다.
일반 수령액 70%는 임시 가정입니다. 제19회 대체 모드의 기본값은 보도된 약 실수령액을 사용합니다.
당시 세법·최저상금 보증 규칙을 모두 재현하지 않습니다.

지역 85곳은 2024년 말 행정구역을 기준으로 시·도 그룹 안에서 인구순으로 정렬했습니다.
화면에는 인구 숫자를 표시하지 않습니다. 군·구와 과거 행정구역 변화는 제외했습니다.
달력은 한국시간 일~금 06:00~24:00, 토요일 06:00~20:00 기준입니다.
토요일 20:00은 마감으로 처리합니다. 과거 전체에 같은 판매시간 규칙을 사용합니다.

생애 종료는 75세 이후 매년 16%의 조건부 확률, 100세 상한을 사용합니다.
75세 미만으로 시작하면 평균 약 80.2세인 게임 규칙이며 실제 사망 통계가 아닙니다.
성별·건강은 종료 확률에 영향을 주지 않습니다.

## 저장과 호환

브라우저 localStorage에 자동 저장합니다.
새 삶을 시작하면 기존 슬롯을 덮어쓰므로 먼저 JSON 백업을 내려받으세요.
주소·브라우저가 달라지면 JSON을 직접 가져와야 합니다. 서버 동기화는 없습니다.

이전 기록은 ‘경제 시장 열기’로 전환할 수 있습니다.
현금·예금을 유지하고 이전 단순 주식 평가액을 IF 분산시장으로 옮깁니다.
과거 장부와 손익을 다시 계산하지 않습니다.

## 파일 구조

- `dist/`: 웹 실행 파일과 소스. 별도 번들 단계가 없습니다.
- `dist/engine.js`: 월 회계·선택·시간 진행·저장 검증.
- `dist/market.js`: 가격·수량·원가·거래·시장 보고서.
- `dist/market-data.js`: 가상 종목과 세계 경제 사건.
- `dist/policy-data.js`: 취임·정책 사실, 출처, 정책 효과 가정.
- `dist/market-ui.js`: 시장·차트·거래·정책 화면.
- `dist/lottery*.js`, `dist/regions.js`: 로또와 지역 자료.
- `dist/lifestyle*.js`, `dist/stories*.js`, `dist/shop-data.js`: 생활·분기·상점 콘텐츠.
- `tests/`: 자동 테스트.
- `scripts/`: 정적 검증과 웹 폴더 내보내기.
- `.github/workflows/`: 전용 저장소를 위한 수동 Pages 배포 예시.
- `examples/lottery-records.json`: 회차 자료 가져오기 예시.

시장 재현성·수수료·자산 보존·금의 환율 계산·원가·이자·사건 중복 방지·정부 정책 시점·저장 호환·생애 종료를 검증했습니다.
모의 DOM에서 설정·달력·추첨·시장·매수/매도·생활 선택 경로를 확인했습니다.
